## 2. 核心对局循环

```
进入对局
  → 开局赠送少量馒头
  → 花馒头“征兵”：一次刷出 5 张牌（士兵 / 武将字 / 铲子）
  → 把牌拖到已解锁格子：士兵自动攻击，武将字先占格
  → 两个同字同级士兵合成更高一级
  → 凑齐武将姓名的两个字，按顺序放在场上，觉醒武将
  → 击杀敌人获得馒头；漏怪扣阿斗生命
  → 用馒头继续征兵 / 用铲子扩格 / 用道具强化
  → 先失去全部生命的一方落败；撑到高波或对手先崩即胜
```

局外循环：

```
对局胜利/失败
  → 获得金币与武器掉落（品质白/绿/蓝/紫/金）
  → 金币购买每日随机刷新的主动/被动道具
  → 武器装备给对应武将，蓝以下可出售换金币
  → 军衔/星级成长，解锁更多系统与地图
  → 每日 0 点刷新道具/技能/地图，金币、武器、等级保留
```

## 3. 对局规则拆解

### 3.1 胜负与生命

- 1v1 对称竞技：双方各守一个“阿斗”，阿斗头顶红心即生命。
- 生命默认 3 点，随军衔/模式可提升到最多 9 点（GameRes）。
- 敌人沿路径走向阿斗；碰到即扣 1 点（Boss/精英可能更多，玩家实测高波 Boss 压力显著）。
- 一方生命归零即败；多数对局在 Boss 前结束，因此“第 6 波 Boss”更像压力测试而非固定终点。
- 对局存在高波/无尽延伸：玩家讨论中出现 20 波、连续多个 Boss 的情况（TapTap）。
- **设计含义**：生命是“失误预算”，不是血条；3 点让每次漏怪都肉痛，9 点则允许更激进的扩张。难度调参应该调“失误预算”，而不是只调敌人血量。

### 3.2 地图与格子

- 战场是有限方格；可放置区与不可放置的绿色地面分开。
- 开局只有少量可放置格（玩家实测约 6 块基础格）。
- “铲子/洛阳铲”可以挖开绿色地面，把不可放置格变成可放置格；扩张是随机的、有限的，因此“先扩哪、扩多少”是核心取舍。
- 官方/媒体提到 4 张地图：巨鹿、云梦泽、虎牢关、赤壁；格子数与布局不同（GameRes）。第三方复刻使用 8×10 上下镜像地图（D 级）。
- 路径沿边缘/对角线推进，防守方需要同时覆盖多条路；敌人从一侧出现，绕行到阿斗。
- **设计含义**：地图不是背景，而是“阵型预算”。格子越少，合成与站位越重要；格子越多，兵力越分散。扩张必须有代价，否则最优解永远是“全开”。

### 3.3 波次与 Boss

- 敌人按波次从固定入口出现，沿路径推进。
- 击杀给馒头；漏怪扣生命。
- 第 6 波出现 Boss；Boss 带范围迷惑/控制技能，被迷惑单位短时间无法攻击（17173）。
- 高波继续出现 Boss/精英；玩家实测 20 波后仍有第 4 个 Boss，需要特定武将/控制链（TapTap）。
- 单局节奏：前期 1–5 波是开荒，6–12 波成型，12 波后进入资源循环/控制链；这是玩家攻略的共识分段（TapTap、GameRes）。
- **设计含义**：Boss 不是“血量墙”，而是“规则改变器”（迷惑、推进、召唤）。每 5 波左右引入一次规则变化，比线性加血更有记忆点。

### 3.4 单位与合成

四大基础兵种（玩家/媒体一致）：

| 兵种 | 定位 | 攻击范围 | 攻速 | 特点 |
| --- | --- | --- | --- | --- |
| 刀 | 近战快攻 | 极短 | 快 | 便宜、清小怪 |
| 枪 | 中距 | 中 | 中 | 稳定、适合路口 |
| 弓 | 远程速射 | 长 | 快 | 脆、放内圈 |
| 骑 | 重击 | 短 | 慢 | 高伤、适合堵路 |

合成规则：

- 两个**同字、同等级**的士兵可以合成一个同字、等级 +1 的士兵。
- 等级上限 5（玩家实测/第三方复刻）；每级属性约 ×2.1（复刻数值，非官方）。
- 合成是免费的，但会消耗一个场上的格子/单位；因此“合成”同时是“升战力”和“腾格子”。
- 只有 5 个备战席（GameLook 提到 5 个兵营格；复刻配置也是 5）：征兵会整体替换备战席，玩家必须快速取舍。
- 低阶兵到后期会占格，需要“垃圾桶”回收；高等级兵放入备战席再点征兵，会按等级折算成馒头（玩家实测隐藏经济规则）。
- **设计含义**：合成不是“收集图鉴”，而是“空间换质量”。如果合成不消耗空间，玩家会无脑合成；如果合成消耗空间，才有“广铺 vs 精铺”的决策。

### 3.5 武将/字谜

- 征兵可能出金色单字碎片；单字不能作战，只占格。
- 需要凑齐武将姓名的两个字，并按正确顺序放在场上，才能觉醒（17173、GameRes）。
- 武将品质：金色（关张赵马黄、刘备曹操等）> 紫色（关兴、张苞、黄祖、黄盖等）> 更低品质（攻略提及，未完全验证）。
- 武将拥有更高属性、独特攻击模式、定时技能、击杀升级；例如黄忠全屏射击、张飞当阳爆喝、赵云贯穿、刘备范围眩晕、关羽跳劈击退（TapTap、GameRes）。
- 武将可装备武器，武器改变攻击范围/特效/专属被动；武器有品质与掉落，蓝以下可出售。
- 隐藏机制：累计 99 次合成马超可解锁“锦马超”（玩家实测，未官方确认）。
- 玩家实测名将上限约 7 名（15 个字），通常 5 名 + 2 个散字；散字会长期占格，形成“赌不赌下一次抽卡”的决策。
- **设计含义**：字谜是“延迟满足 + 知识门槛”的组合：抽到半个名字时，玩家会为了凑齐而继续投入。它比直接抽整卡更有赌博感，但也更容易产生“卡散字”的挫败。对《穗守》的映射不应是汉字，而是“组合式守护灵/作物谱系”：两个同系碎片合成一个完整守护灵。

### 3.6 经济（馒头）

馒头是局内唯一基础货币，来源与去向：

| 来源 | 数值/规则 | 证据 |
| --- | --- | --- |
| 开局赠送 | 少量（复刻 20） | D 级 |
| 击杀敌人 | 小怪 1–5，Boss 30（复刻） | D 级 |
| 波次奖励 | 每波额外馒头（复刻 8 + 2×波） | D 级 |
| 农民 | 定时产馒头；3 级 5s/个、4 级 3s/个、5 级 2s/个 | C 级玩家实测 |
| 高等级兵回收 | 放入备战席后点征兵，按等级折算馒头 | C 级玩家实测 |
| 铲子+农民循环 | 开地→放农民→回收地块→重新开垦，刷馒头 | C 级攻略；属于设计漏洞级机制 |

主要去向：

| 去向 | 规则 | 证据 |
| --- | --- | --- |
| 征兵 | 每次消耗递增；一次刷 5 张 | B/C 级 |
| 扩格 | 铲子/洛阳铲；也可用金币买 | B/C 级 |
| 刷新/道具 | 局外金币买每日道具 | B/C 级 |
| 合成 | 免费，但消耗单位/格子 | B/C 级 |

- 征兵费用递增是核心“反无限抽卡”阀门；没有它，农民经济会迅速失控。
- 玩家发现“农民 + 铲子”循环可以把地图格子反复开垦刷馒头，说明**任何“可逆的格子操作 + 产出单位”都会产生套利**；必须在设计时明确“回收是否返还资源”“开垦是否可逆”。
- **设计含义**：经济系统要有至少两个阀门：**递增抽卡成本**与**有限空间**。只靠击杀掉落，后期会通胀；只靠固定成本，前期会卡死。

### 3.7 商店 / 道具 / 武器

局外道具（每日刷新）：

- 分主动/被动；主动只能装 2 个，被动约 6 个（玩家称“2+6”；微信文章标题也提到 2+6）。
- 主动：攻速符、神兵符、毛笔（改字）、练兵符等。
- 被动：农民、洛阳铲、金铲铲、招贤令/招贤榜、齐头并进、攻速、陨石、续命丹、降妖符、摸金校尉、升职券、垃圾桶等。
- 道具只当日有效；金币、武器、等级保留；每日 0 点刷新。
- 隐藏 bug/机制：0 点在线（含后台）时不刷新（本地端；玩家实测）；新赛季清空装备并折算金币，引发差评（TapTap）。
- 商店不是一开始就有：玩家反馈“玩了好几天都没有商店”，说明商店是军衔/进度解锁的，且引导不足。
- 武器：品质白/绿/蓝/紫/金（或橙），胜利掉落；装备给对应武将；蓝以下可出售；武器可改变攻击范围/专属被动。
- **设计含义**：局外成长要“每天给一点新变量”，但不能清空玩家积累；赛季重置必须有补偿/继承规则，否则会直接摧毁信任。

### 3.8 排位 / 每日 / 赛季

- 胜利 +1 星，失败扣星/掉级；达到星级提升军衔；军衔解锁头像、更多玩法/系统（GameLook）。
- 每日地图轮换、道具刷新；局外 buff 仅当日有效。
- 赛季（S2）重置装备/段位，玩家差评集中在“没有新玩法却清空积累”。
- 排行榜（省/全国）是持续动力之一；IAA 广告换体力/铲子/抽卡/金币。
- **设计含义**：每日随机 + 赛季重置是留存工具，但必须有“新内容”与“继承/补偿”配套；否则是负体验。

### 3.9 PvP 与 AI（重要）

- 官方口径/媒体：1v1 对称竞技，双方各守阿斗。
- 玩家实测：**大多数对局对手是 AI**；“你技能越多，匹配的电脑技能越多；你越久不更新技能，电脑满配概率越高”（TapTap 玩家总结）。
- 这意味着它的“PvP”本质是 **异步/镜像 AI 对战**：用玩家的成长曲线生成一个势均力敌的对手，保证匹配速度与胜率区间。
- 对局结束条件：一方生命归零；多数在 3 分钟内结束。
- **设计含义**：对没有后端、没有实时同步的静态网页游戏，做“异步镜像 PvP”是合理且诚实的方案；不要伪装成实时真人 PvP。关键是让对手的行为可解释、可复盘、有性格。

### 3.10 “闯关 Roguelike 战后三选一”的证据缺口

用户要求调研“闯关 Roguelike 战后三选一 buff 系统”。在可访问的 A/B/C 级来源中：

- 能确认的 Roguelike 元素是：**随机征兵（抽卡）、随机武将碎片、每日随机道具/技能、随机地图/格子布局**。
- 不能确认存在一个独立的“闯关模式 + 每战结束三选一 buff”系统。
- 部分 SEO 攻略提到“每局胜利三选一奖励，优先选粮草补给、兵书残卷”（ali213 0 氪攻略），但同一批站点也产出与真实玩法矛盾的“动作护送/长坂坡潜行”内容，可信度低，不能作为官方设定。
- 因此，本文的结论是：**《赵云与阿斗》的 Roguelike 核心是“随机 draft + 每日 build”，不是《杀戮尖塔》式战后三选一。** 《穗守》的“季令三选一”是明确的本地化再设计，而不是对原作的 1:1 复刻。

## 4. 隐藏机制、漏洞与玩家反馈

### 4.1 隐藏机制/技巧

| 机制 | 说明 | 证据 |
| --- | --- | --- |
| 攻速符连滑 | 快速反复拖到同一单位上可叠加多次攻速；英雄双卡拆合 3 次还能额外加 | C 级 |
| 神兵符连滑 | 快速拖拽可连续升级；2 级农民滑 3 次到 5 级 | C 级 |
| 农民 + 铲子循环 | 开地→放农民→回收→重开，刷馒头 | C 级 |
| 高等级兵回收 | 放进备战席点征兵，按等级折算馒头 | C 级 |
| 99 次合成马超 | 解锁“锦马超” | C 级 |
| 黄忠攻速后升级 | 会触发输出 bug（玩家称） | C 级，未官方确认 |
| 0 点在线不刷新 | 本地端每日刷新被“在线状态”卡住 | C 级 |
| AI 技能随玩家增长 | 玩家越强，AI 技能越多；久不更新技能，AI 更容易满配 | C 级 |
| 名将上限 | 约 7 名（15 字），通常 5 名 + 2 散字 | C 级 |
| 赛季清空装备 | S2 把装备折算成金币，玩家强烈不满 | C 级 |

### 4.2 玩家正反馈

- “抽卡 + 合成 + 摆位”上手快，3 分钟一局，适合碎片时间。
- 汉字变形/水墨技能有辨识度；低美术成本做出差异化。
- 随机性降低失败挫败：“如果随到 XXX 就赢了”。
- 控制链成型后很爽：张飞/刘备/关羽把怪控在起点，黄忠/赵云输出。
- 排行榜、军衔、每日刷新提供长期目标。

### 4.3 玩家负反馈/风险

- **运气权重高**：抽不到关键武将字，散字占格，容易“非酋局”。
- **AI 伪装 PvP**：玩家发现对手是 AI 后，竞技感下降；AI 技能随玩家增长也会让人觉得“被系统安排”。
- **每日/赛季重置**：清空积累、没有新内容，直接差评。
- **商店解锁不清晰**：玩几天看不到商店，缺少引导。
- **bug/平衡**：黄忠攻速升级 bug、农民铲子无限刷、高波数值膨胀。
- **后期重复**：20 波后靠控制链拖时间，操作同质化。
- **广告依赖**：体力/铲子/抽卡与广告绑定，影响节奏。

### 4.4 对《穗守》的直接警示

1. 不要做“伪实时 PvP”；如果做异步 AI，就在 UI 和文案里说清楚。
2. 每日/赛季重置必须给继承或补偿；单机网页游戏最好不做强制清空。
3. 任何“可逆格子操作 + 产出单位”都要做套利审计（《穗守》的开垦/拆塔/合成也要）。
4. 随机 draft 要有保底/去重/上限，避免“散字卡死”。
5. 商店要在玩家第一次需要它的时候出现，并给出明确引导。
6. 不要把“数值膨胀”当难度；用规则变化（Boss 技能、路径、禁建格）制造压力。

## 6. 设计启示：哪些可以借鉴，哪些不能

### 可以借鉴

1. **短局 + 高决策密度**：3–5 分钟一局，每 10–20 秒一个选择（征兵、合成、扩格、道具）。
2. **合成 = 空间换质量**：同阶二合一，消耗格子，迫使玩家在“广铺”与“精铺”间取舍。
3. **抽卡式 draft + 保底**：随机性制造复玩，但必须有去重、上限、保底，避免卡死。
4. **生命 = 失误预算**：少血量让每次漏怪都有感；难度调“预算”而不是只调血量。
5. **Boss = 规则改变器**：迷惑、推进、召唤，而不是纯血量。
6. **每日随机变量**：地图、商店、季令每日/每局变化，低成本拉长生命周期。
7. **异步镜像对手**：用 AI 模拟“势均力敌的对手”，适合无后端产品；但必须诚实标注。
8. **极简表现**：低成本也能做出辨识度；关键是规则可视化，不是堆美术。

### 不能照搬

1. **汉字/三国皮肤**：《穗守》是 3D 第一人称种田塔防，皮肤必须服务自己的世界观。
2. **伪实时 PvP**：没有后端就不要假装真人；做异步 AI 或本地双人。
3. **赛季清空积累**：单机网页游戏没有 live-ops 团队，清空只会赶走玩家。
4. **广告换资源**：当前《穗守》是纯单机、无广告；不要为了“像小游戏”而加广告。
5. **无限刷资源漏洞**：农民+铲子循环是反面教材；《穗守》的开垦/拆塔/合成必须做套利审计。
6. **纯数值膨胀的高波**：20 波后靠控制链拖时间，重复度高；用规则/地图变化替代。

## 8. 结论

《赵云与阿斗》的成功不是“玩法有多深”，而是把 **抽卡、合成、塔防、扩格、每日 build** 压缩进了一个 3–5 分钟、几乎零学习成本的循环里，并用汉字/三国题材做出记忆点。它最值得《穗守》学习的是：

- 用**短局 + 每波决策**替代长局刷数值；
- 用**合成消耗空间**制造真实取舍；
- 用**随机 draft + 保底**制造复玩；
- 用**生命预算**让失误有代价；
- 用**规则型 Boss**制造高潮。

同时要避开它的坑：伪 PvP、赛季清空、随机卡死、无限资源漏洞、后期纯数值膨胀。

《穗守》v2 的完整设计、数值与边界规则见 [`design-v2.md`](design-v2.md)。
